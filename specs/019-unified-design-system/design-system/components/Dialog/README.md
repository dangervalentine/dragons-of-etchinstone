# Dialog

A question the game must ask before something it cannot undo (Unspent XP, leaving a game).

- Over `scrim`. `stone` panel, `chamfer-lg`, 360pt wide, `space-5` padding.
- Title in `title` as the question itself; body in `parchment-muted` says the consequence in one sentence.
- Two buttons: the safe way back in stone on the left, the answer to the question in brass on the right.
