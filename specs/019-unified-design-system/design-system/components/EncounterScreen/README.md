# EncounterScreen

A showcase, not a component: the Enemy Encounter rebuilt from the system at a real phone size (844×390pt), to judge the whole before changing the game.

- Ground washed with `region-jade`; top bar, tray panel and action row in stone; the Encounter card is the brightest thing on screen because the chrome no longer competes with it.
- Brass appears twice: the target slot (Boost) and the selected card. Play stays disabled until the set is full, then becomes the one brass button.
- The Encounter art is the game's own, cropped from the current screens.
