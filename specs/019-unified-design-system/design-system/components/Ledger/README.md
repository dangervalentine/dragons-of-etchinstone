# Ledger

Tables of records: Leaderboard and History.

- Column heads in `label`, `parchment-muted`. Rows in `body-sm`, `line` hairlines between them, 6pt vertical padding (rows stay ≥ 30pt; the whole row is the tap target when it opens a game).
- Scores in `numeral` style, tabular. Place and absent values (—) in `parchment-muted`.
- The best row is `brass-bright`, and only the best row.
