# Banner

A full-width moment: a new Region, Victory, Defeat. Shown over `scrim`, then cleared.

- `stone` fill, `chamfer-lg`, rim in the Region's own tint (`region-jade`, `region-marsh`, `region-basin`, `region-gath`, `region-lair`), so each Region announces itself in its painted colour rather than the same gold.
- Kicker in `label` (`parchment-muted`), headline in `banner` (`brass-bright`, uppercase).
- Medallion ring in the Region tint around the Region's own glyph.
- Victory uses `region-lair` for its rim and `brass-bright` headline; Defeat uses `danger` rim and `parchment` headline.
