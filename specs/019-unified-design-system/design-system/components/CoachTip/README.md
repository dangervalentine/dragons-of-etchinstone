# CoachTip

Lessons, glossary pop-ups and the rulebook are read, so they are printed on paper.

- `paper` fill, `paper-ink` text in `body`, `paper-muted` for the footer and rules. A 1px darker paper edge and `shadow-card` lift it off the table.
- Glossary terms are bold with a `brass-deep` underline; tapping one opens its entry.
- A small pointer aims at the thing being taught; the target itself gets the `brass` ring.
- Max width 340pt, about 50 characters a line. The current tip is dark-on-dark and nearly the same colour as the panels behind it.
