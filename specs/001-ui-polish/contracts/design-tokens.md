# Contract: Design Tokens

The single visual language required by FR-004. Every widget takes its sizes,
colours, type and timings from these tokens (`ui/theme/tokens.gd`); no widget
defines its own. Values marked *tune* are starting points to adjust by eye during
implementation; the roles and the minimums are fixed.

## Units

One design unit is one pixel of the 1280 x 720 landscape layout, about half a
point on a phone held sideways. The layout solver sets the scale (see research.md, R4).

| Token | Units | Use |
|---|---|---|
| `space.xs` | 4 | Inside chips |
| `space.s` | 8 | Between related items |
| `space.m` | 16 | Screen margin, between regions |
| `space.l` | 24 | Between groups |

| `radius.s` / `radius.m` / `radius.card` | 8 / 14 / 18 | Corners |
| `tap.min` | 88 | **Minimum** for anything interactive that plays the game |
| help target | 44 | Minimum for a figure or effect that only explains itself when pressed |

## Colour roles

Dark, warm-neutral surfaces so the four Ether colours carry the meaning. Values
are *tune*.

| Token | Value | Role |
|---|---|---|
| `bg.base` | `#100e17` | Screen background (with a vignette) |
| `bg.surface` | `#1d1a29` | Panels, regions |
| `bg.raised` | `#2b2640` | Cards' frames, raised controls |
| `line.soft` | `#3d3757` | Dividers, idle borders |
| `ink.primary` | `#f1ecdf` | Main text (warm white, like the card print) |
| `ink.muted` | `#a69fb8` | Secondary text |
| `accent.gold` | `#f2d16b` | Primary action, XP, Level crown, selection |
| `state.good` | `#6fcf8e` | Complete victory, covered damage |
| `state.caution` | `#e9b44c` | Narrow victory |
| `state.bad` | `#ff6b5e` | Loss, damage, fatal warning |
| `ether.fire` | `#e2543a` | Fire |
| `ether.water` | `#4a9cf0` | Water |
| `ether.lightning` | `#e8ad2a` | Lightning |
| `ether.shadow` | `#a56cf0` | Shadow |

**Rules**
- An Ether colour never appears without that element's icon (FR-015).
- Verdicts and costs never rely on colour alone: each has an icon and a word.
- Text on `bg.*` meets a contrast ratio of at least 4.5 to 1; text placed on an
  Ether colour uses `bg.base` ink, as today.
- `accent.gold` marks exactly one primary action per screen (FR-005).
- `state.caution` and `ether.lightning` are close in hue; they are never used in
  the same region without their icons.

## Elevation and state

| State | Treatment |
|---|---|
| Idle control | `bg.raised`, `line.soft` border |
| Hover (mouse) | Border brightens, lifts 2 units |
| Pressed | Scales to 0.96, darkens |
| Focused (keyboard) | 3-unit `accent.gold` ring, offset 3 |
| Disabled | 45% opacity, no lift, reason shown nearby |
| Card available | Full colour, soft shadow |
| Card assigned | Lifted, gold edge, role ribbon with the role's icon |
| Card reserve | Thin dashed edge, "Reserve" ribbon |
| Card fused | Top card with the bottom card's edge visible behind, chosen Ether badge |
| Card selected (setup, soak) | Gold edge, order number |
| Card downgraded | Cracked-edge overlay and a down-arrow on the crown |
| Card unavailable | Desaturated, 45% opacity, reason caption |

## Motion

| Token | Seconds | Curve | Use |
|---|---|---|---|
| `motion.instant` | 0.08 | linear | Press feedback |
| `motion.fast` | 0.15 | ease out | Hover, chips, reduced-motion fades |
| `motion.base` | 0.25 | ease out cubic | Screen and panel transitions, consequences |
| `motion.move` | 0.35 | ease in-out cubic | Card travel |
| `motion.count` | 0.6 | ease out | Totals counting up |
| `motion.reveal` | 0.4 | back out | Verdict, banners |
| `motion.stagger` | 0.12 | | Between dealt cards |
| `motion.sequence_max` | 3.0 | | Cap on a whole resolution sequence |

**Reduced motion**: every travel, scale-in, shake and particle becomes a
`motion.fast` cross-fade or an instant change. Counting numbers jump to their
value. Nothing is removed from the sequence.

## Icons

All icons are single-colour vector shapes generated by `tools/gen_icons.py`, tinted
at draw time. Additions for this feature: deck, discard, trash, reserve, spell,
element (role), fuse, divert, regroup, inspect, menu, settings, help, skip, victory,
narrow victory, loss, down-arrow, a sigil for each of the four Ethers and each of
the four dragons.
